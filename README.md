Project Idea:
Development of a program for working with binary sequences and evaluating their randomness. During the project, the following will be implemented: NIST statistical tests in Python, an algorithm for generating an output file containing randomness evaluation results along with graphs and charts illustrating test outcomes, an algorithm for creating a web interface for inputting a binary sequence and selecting the physical phenomenon used to generate it, and an algorithm for processing experimental data that converts physical parameters into a binary sequence.
